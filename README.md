# Evolvia Digital Studio

Create a premium Spanish-first technology agency landing page for Evolvia, designed for Brazil and Latin America. Visual direction: dark graphite canvas, vivid acid-lime accent, elegant typography, editorial layout, subtle motion, bespoke abstract automation/network visuals, strong conversion hierarchy. Sections: navigation, hero, trust strip (do not invent customer logos or metrics), services, interactive workflow demo, process, portfolio with clearly labeled concept projects, FAQ, contact form, footer. Make it responsive, accessible, SEO-conscious, polished and not a generic AI template. Do not claim integrations work unless implemented. This is a design prototype; prioritize the visual frontend and real interactions that can work in the Lovable preview. Spanish copy with Portuguese-ready structure.
